# Laundry POS System

A desktop-based **Laundry Point-of-Sale (POS) System** developed using VB.NET and Microsoft Access. The system is designed to help laundry businesses manage customer transactions, laundry services, and sales records through a simple and user-friendly interface.

## 🧺 Features

* Customer information management
* Laundry service selection
* Transaction management
* Automatic calculation of total costs
* Order and payment tracking
* Sales and transaction records
* Database-driven system
* User-friendly graphical interface

## 🛠️ Technologies Used

* **VB.NET**
* **Microsoft Access**
* **Windows Forms**
* **Figma** – UI/UX Design

## 📌 Project Overview

The Laundry POS System is a desktop application developed to streamline common laundry shop transactions.

The system allows users to manage customer orders, select laundry services, calculate transaction totals, and store transaction information in a Microsoft Access database.

The application's interface was designed in **Figma** before being implemented using VB.NET Windows Forms.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/K-mariedizon/Laundry-POS-System.git
   ```

2. Open the project in **Visual Studio**.

3. Make sure the required VB.NET and Microsoft Access components are installed.

4. Verify that the database connection points to the included Access database.

5. Build and run the application.
